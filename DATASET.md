# Dataset Information

## Cat and Dog Image Classification

This project uses a dataset of cat and dog images to train a Convolutional Neural Network (CNN) for binary image classification.

### Dataset Source
- **Platform:** Kaggle
- **Dataset Name:** Cat and Dog
- **Dataset Link:** https://www.kaggle.com/datasets/tongpython/cat-and-dog

### Dataset Usage
The dataset is used for training and testing the CNN model to classify images into two categories: Cats and Dogs.

### Dataset Structure
- Training images: Cats and Dogs
- Testing images: Cats and Dogs

### Note
The dataset is hosted on Kaggle and is not included in this repository due to its large file size.
